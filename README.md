# Gallia
## An open-source barebones Kernel
### made exclusively for educational purposes

As the sub-sub title suggests, this Kernel was made for the explicit purpose of me learning more about System dev.

It is nothing special ( especially at the current state ) but it is a project i am quite proud of

However at the moment, its development is on a hiatus that i do not know how long it will last.
Sadly i realized that maybe im not quite cut out to continue working on this project at the moment,
so instead of trying to make something that i 1. Wouldn't be proud of, or 2. Could barely understand
i decided to put it on a temporary hiatus, so i could work on side projects that would teach me enough
for me to confidently be able to come back to this project.

thanks for understanding and when i come back i promise I'll make it a full on kernel

you never know...

maybe one day it'll be as popular as Linux :]
